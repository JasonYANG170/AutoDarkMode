## Features
- ✅ Switch to dark mode regularly
- ✅ Switch light mode regularly
- ✅ Auto-start at boot
- ✅ Running in the background

**This project's features have been merged into Health-Protection.**
Now all functions of the program can be used normally.
No new bugs have been discovered yet. If you encounter any, please let me know.
# Instructions for use
After entering the set time (24-hour format), dark mode will be activated when it is greater than or equal to the set time.

To ensure that the program runs stably, please select the program background run button.
